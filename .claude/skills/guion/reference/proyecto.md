# Los textos de Sin Retaguardia (mapa del proyecto)

_Vacío por ahora: aún no hay textos._ Aquí irá lo que es de este juego, y no del oficio:

- dónde vive cada familia de textos (interfaz, órdenes, gritos, unidades, armas, mapas, informes, campaña);
- cómo se traduce (el mecanismo, las tablas inglesas) y cómo se comprueba;
- los bandos, el teatro y la época de cada campaña, y la voz de cada bando;
- las decisiones de estilo del proyecto (tú o vosotros, inglés británico o estadounidense).
